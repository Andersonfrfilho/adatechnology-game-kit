# @adatechnology/game-graphics

The player's graphics settings without any engine: presets (Automatic, Low, Medium, High, Ultra), resolution scale, horde detail, shadows, view distance, FPS cap and counter, the automatic mode driven by the frame time, a short calibration on load, the choice kept in the browser, and a plain DOM settings screen.

API, uso e exemplos: `packages/game-graphics/README.md`; testes em `packages/game-graphics/tests/`.
