# @adatechnology/game-kit-defaults

The default preset of the game kit (L5 composition): imports the content packs and returns the ready options the cores and adapters take by option, like Bevy's DefaultPlugins. A game that wants other content leaves it out.

API, uso e exemplos: `packages/game-kit-defaults/README.md`; testes em `packages/game-kit-defaults/tests/`.
