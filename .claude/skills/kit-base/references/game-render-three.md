# @adatechnology/game-render-three

Owner of the GPU-facing state of a three.js game: the one ThreeLib type, a LightBudget with a fixed number of lights (slots, priority, fades), a ProgramWarmup that links every shader program at load and keeps it linked, and geometry and material pools.

API, uso e exemplos: `packages/game-render-three/README.md`; testes em `packages/game-render-three/tests/`.
