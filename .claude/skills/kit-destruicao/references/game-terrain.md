# @adatechnology/game-terrain

Deformable ground: a height field in chunks with strata per column (turf over soil over rock, asphalt over gravel, tile over mortar over slab). Blows dig the top stratum and reach the next when it runs out, down to a limit each profile has; fine marks with a budget per area; thrown clods that collide; fire that chars and spreads.

API, uso e exemplos: `packages/game-terrain/README.md`; testes em `packages/game-terrain/tests/`.
