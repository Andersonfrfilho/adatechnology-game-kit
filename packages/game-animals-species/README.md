# @adatechnology/game-animals-species

The 13 species of the Bichos do Vale as data for `@adatechnology/game-animals` (body spec, gaits, sound range, infection outcome and the optional `outbreak`
rule), in `en` and `pt-BR`. Generated by `tools/animals-catalog`.

```ts
import { getSpecies } from '@adatechnology/game-animals-species'

getSpecies('pig')?.outcome // 'turns'
```

Plain script: `dist/index.global.js` exposes the `GameAnimalsSpecies` global.
