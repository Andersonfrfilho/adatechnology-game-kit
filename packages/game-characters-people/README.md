# @adatechnology/game-characters-people

Generic people for `@adatechnology/game-characters`: 12 professions as presets (look, accessories, what they carry, the protection they wear), 4 age
presets, appearance pools and the ids of the accessories the portraits builder knows, in `en` and `pt-BR`. Named people and their stories stay in the game.
Generated by `tools/characters-catalog`.

```ts
import { createCharacters } from '@adatechnology/game-characters'
import { createPeoplePack } from '@adatechnology/game-characters-people'

const kit = createCharacters({ packs: [createPeoplePack()] })
kit.create({ seed: 5, kind: 'nurse' })
```

Plain script: `dist/index.global.js` exposes the `GameCharactersPeople` global.
