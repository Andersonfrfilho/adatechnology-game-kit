# @adatechnology/game-characters-uniformed

Generic uniformed forces for `@adatechnology/game-characters`, with the real Brazilian names as `br` content: army, military police, civil police, highway
police, prison police, special forces and tactical units. Rank ladders with the command rule (the highest rank alive takes command; an opinion below -20
allows disobedience), loadouts as weapon and item ids, and loot pools shaped like a `FindsProvider`. The valley and its units stay in the game.
Generated by `tools/characters-catalog`.

```ts
import { createForceFinds, pickCommander } from '@adatechnology/game-characters-uniformed'

createForceFinds().findsFor({ place: 'checkpoint', container: 'army', state: 'normal', rng: Math.random })
```

Plain script: `dist/index.global.js` exposes the `GameCharactersUniformed` global.
