# @adatechnology/game-physics-rapier (spike)

`@adatechnology/game-physics` on Rapier (dimforge, Apache-2.0), deterministic build by default (`loadRapierEngine()`), or any build passed to
`createRapierEngine({ rapier })`. Engine-specific parts used by the spike tests through `RapierWorld.world`: character controller, ray-cast vehicle.

Licence: Rapier is Apache-2.0 (no NOTICE file upstream); a bundle that inlines it must ship its LICENSE text.

Spike of 2026-11-13 (engine decision, Jolt vs Rapier): not published, not stable.
