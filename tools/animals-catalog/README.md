# animals-catalog

Writes the data of `game-animals` and `game-animals-species` from Bichos do Vale (`sources/animais__bichos-do-vale.js`), and the game slice for the zombiada repository.

| Reads | What |
|---|---|
| `SPECIES` | 13 species: group, phase, infection outcome (`vira`, `morre`, `imune`) and the texts |
| `SPEC` | the body spec of each species (`q` quadruped, `b` bird, `snake`), `walkHz`, `runHz`, `gallop`; the `extra` builder closures are not data (flagged `hasExtraBuilder`) and the canvas textures become `{ kind, base, … }` markers |
| `GAIT`, `ORDER` | the three phase tables (walk, trot, gallop) in radians and the production order |
| `ZONES`, `TER` | where each species lives and the terrain: game slice |
| `decisions.json` | English ids and names, group and phase ids, the infection rule (turn and death times, carcass lure, raw meat), the sound ranges, each with the snippet of the source that proves it |

| Writes | |
|---|---|
| `packages/game-animals/src/data/gaits.json` | generated |
| `packages/game-animals-species/src/data/species.json` | generated |
| `specs/001-migracao-entregas-dos-times/game-slice/animals/` | generated by `--game-out`; goes to the zombiada repository |

```bash
pnpm --filter @adatechnology/animals-catalog-tool build
pnpm --filter @adatechnology/animals-catalog-tool catalog          # regenerate
pnpm --filter @adatechnology/animals-catalog-tool catalog:game     # regenerate the game slice
pnpm --filter @adatechnology/animals-catalog-tool catalog:check    # fail when the generated files are stale
```

`tests/sources.test.ts` checks the generated data against the page; `tests/catalog-up-to-date.test.ts` is the same as `catalog:check`.
