# characters-catalog

Writes the reconciled data of `game-characters` and `game-characters-undead` from the team deliveries, so every number has a traceable origin,
and the game slice for the zombiada repository.

| Reads | What |
|---|---|
| Jogo (`artefatos/2UG1…/jogo.js`) | `CATS` (13 types), `IDADES`, `ROUPAS`, `SEG`, `CALIBRES`, `INFEC`, `FERIDA`, the joints `J`, the corpse limits, `LOD_D`, the walk constants, `BEST` v17 `TYPES` and `OUTFITS`, `ZONES`, `NPC` |
| Bestiário (`sources/zumbis-personagens__bestiario.js`) | `Z` (the 13 cards, with the text of role, AI, counter and voice), `GAIT`, `CASC`, `BASE`, the age table in the visible text |
| Elenco (`…__elenco.js`) | `PROFS` (12 professions), `STAGES` (infection hours), `MOVES`, the cut weapons, `BELOW`/`FALLS` and the segment hit points |
| Retratos do Vale / Os Vivos do Vale | `PEOPLE` (44), `GROUPS` (18), `NPCS`, relations, events, `FACT`, `RANKS`, `RANKRULE`, `LOOT`, `GENT`, the life simulation source |
| Galeria 3D do Arsenal (`…galeria-3d-arsenal.js`) | `BLEED`, `MULT`, `HPS`, `ZW` of the 11-segment body |
| Bancada de Hordas | `CATS` chase speeds (P3) |
| `decisions.json` | every reconciliation choice as `{ value, source, reason }`: English ids, P1 proportions, P3 speeds, the P7 penetration rule, protection presets, severity, moments, abilities, scope |

| Writes | |
|---|---|
| `packages/game-characters-undead/src/data/{types,ages,outfits,infection,moments}.json` | generated |
| `packages/game-characters/src/presets/{team-game,physical}.json` | generated: the game's pen points (golden only) and the P7 rule with its calibration |
| `packages/game-characters/src/data/{body,segments,gait,appearance}.json` | generated |
| `specs/001-migracao-entregas-dos-times/game-slice/characters/` | generated by `--game-out`; goes to the zombiada repository (see its README) |

```bash
pnpm --filter @adatechnology/characters-catalog-tool build
pnpm --filter @adatechnology/characters-catalog-tool catalog          # regenerate the SDK data
pnpm --filter @adatechnology/characters-catalog-tool catalog:game     # regenerate the game slice
pnpm --filter @adatechnology/characters-catalog-tool catalog:check    # fail when the generated files are stale
```

To change an answer (a type id, a speed state, the penetration constants), edit the value in `decisions.json` and regenerate. `tests/sources.test.ts` and
`tests/damage-sources.test.ts` check the generated data against the sources; `tests/calibration.test.ts` is the P7 calibration (9 mm hits 2 bodies, 5.56 hits 3,
.308 hits 4, 7.62×39 hits 3, 00 buckshot 1) against the calibres of `game-weapons`; `tests/catalog-up-to-date.test.ts` is the same as `catalog:check`.

The package folders above are written before the packages exist (`game-characters` and `game-characters-undead` get their `package.json` in the next tasks of Phase 4).
