`undeadCrowdPack()` carries the balance table of the horde physics on each type (`balance`: `stability`, `trip` chance and `driveForce` in N; the crawler is `canFall: false`): the brute holds a file against a wall (2.5, 600 N), the runner, the blind and the charred give way first (0.8).
