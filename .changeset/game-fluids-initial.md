Initial release (0.1.0): renderer-free liquids with containers (level, tilt, temperature, fill, pour, drink, spill, leak through holes), ballistic streams, and stains that grow from a flow front, run downhill, soak and dry from the edge. 19 built-in liquids, scripted item uses (sip, drink, chug, pour, pour_out, open, close), deterministic seeded simulation with serialize/load, and an `en` / `pt-BR` locale table.
