# Game slice: urban

Generated by `node specs/001-migracao-entregas-dos-times/game-slice/urban/extract-valley.mjs` from the Galeria do Vale Cinzento (spec 001, Phase 7).
**This folder goes to the zombiada repository** (`content/urban/`), not to the SDK: it names the valley (its rivers, lakes, cities and the numbers of its relief).
The SDK keeps the generic part (`createTerrain` of `@adatechnology/game-urban`); a copy of this file is the fixture of its tests.

| File | What | Source |
|---|---|---|
| `valley-terrain.json` | The valley as `TerrainOptions`: the world frame (320 m, 180 segments, plan x 0.4 - 160), the rolling base, the Serra and Mata Funda reliefs, 4 levelled cities, 4 rivers with their widths and beds, 4 lakes, the forest density, the vertex colour rules and the water plane | `hW`, `forestF`, `RIOS`, `RIO_W`, `LAGOS`, `CITIES`, `buildWorld` |
| `extract-valley.mjs` | Writes the file above: arrays read from the page, the numbers of the formulas typed next to the line they come from | |

```ts
import { createUrban } from '@adatechnology/game-urban'
import valley from './valley-terrain.json'

const urban = createUrban()
const terrain = urban.terrain(valley)          // heightAt(px, py), forestAt, colorAt, nearRiver, toWorld, grid(180)
const b = urban.builder({ seed: 7 })
urban.drawTerrain(b, terrain)                  // the mesh and the water plane, as parts
```
