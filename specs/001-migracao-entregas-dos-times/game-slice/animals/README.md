# Game slice: animals

Generated by `pnpm --filter @adatechnology/animals-catalog-tool catalog:game` from Bichos do Vale (spec 001, Phase 4).
**This folder goes to the zombiada repository** (`content/animals/`), not to the SDK: it names the valley (where each animal lives, the
terrain of the map). The SDK keeps the generic parts (`game-animals`, `game-animals-species`).

| File | What | Source |
|---|---|---|
| `species-texts.json` | Per species: subtitle, where it lives, role, care, yield, sound (pt-BR) | `SPECIES` |
| `zones.json` | Where each species is spawned: `[x, z, radius, place]` | `ZONES` |
| `terrain.json` | Rivers, lakes, roads and cities of the map | `TER` |
